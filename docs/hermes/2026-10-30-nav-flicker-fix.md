# 导航栏闪烁：排查和修复（给 Hermes）

日期：2026-10-30 · 设计：Claude · 实施：Hermes · 状态：**已批准，可以开工**

## 1. 现象
Max 反馈：导航栏有不正常的闪烁。具体出现在哪个场景（滚动、鼠标划过、换页、手机菜单）还没确认，所以先按第 2 节复现，再修。第 3 节的修改无论复现到哪一种都要做：它们本身就是正确的，对性能也有好处。

## 2. 先复现（改之前做，录屏留证据）
在 Mac 的 Chrome 和 Safari 上，用 1280px 和 1440px 宽度，在首页和 `/physical-intelligence` 各试一遍：

| 编号 | 场景 | 操作 |
|---|---|---|
| S1 | 滚动 | 在首页从顶部慢慢往下滚，让 hero 的地球动画滑到导航栏下面，然后停住观察导航栏 |
| S2 | 鼠标横扫 | 鼠标从 About 横向快速划到 Ventures，不停顿 |
| S3 | 文字和箭头之间 | 在一个有下拉的菜单项上，鼠标在文字和右边的小箭头之间来回移动 |
| S4 | 换页 | 用导航连续点 4–5 个不同页面 |
| S5 | 手机 | 390px 下打开菜单，展开 Physical SI，再收起 |

汇报里写清楚：哪几个场景复现了闪烁，在哪个浏览器上。

## 3. 已查到的原因和修改

**F1：导航栏是半透明加毛玻璃，下面的动画会透上来（对应 S1，最可能的原因）**
- **现状：**
  - `.site-header` 背景是 `rgba(4,32,26,.88)`，并且有 `backdrop-filter: blur(14px) saturate(140%)`。
  - 首页 hero 里的 `#hero-globe` 画布一直在动画。页面往下滚以后，画布处在导航栏下面，金色的线条透过 12% 的透明度和模糊效果显出来，看起来就是导航栏在闪。
  - 浏览器每一帧都要重新计算模糊，Safari 上还可能出现撕裂。
- **修改：**
  - `.site-header` 改为不透明的纯色背景，用和 body 相同的 `rgb(4,32,26)`。
  - 删除 `.site-header` 的 `backdrop-filter` 和 `-webkit-backdrop-filter`，`styles.css` 和 `group.css` 两处都要删。
  - 删除 `transition: background`。
  - 底部边框保留。

**F2：下拉菜单的毛玻璃嵌套在导航栏的毛玻璃里面**
- **现状：**`.sub-menu` 背景已经是 98% 不透明，模糊几乎看不出来；但它嵌套在 header 里，两层 `backdrop-filter` 叠在一起，在 Chrome 和 Safari 上都会导致渲染异常。
- **修改：**删除 `.sub-menu` 的 `backdrop-filter`，背景改为不透明。

**F3：滚动时每一帧都在改导航栏阴影（对应 S1）**
- **现状：**`main.js` 每个 scroll 事件都要重写一次 `header.style.boxShadow`。
- **修改：**改成只在状态变化时给 header 切换 `is-scrolled` class，阴影写在 CSS 里。

**F4：鼠标划过时下拉菜单瞬间开关（对应 S2）**
- **现状：**鼠标横扫导航时，每经过一个菜单项，下拉就会弹出又消失。现在 SI 的下拉有 560px 宽，看起来尤其像闪烁。
- **修改：**用纯 CSS 加延迟（只在桌面端 ≥1141px 生效）：
  - 打开延迟 120ms：鼠标短暂经过时不弹出。
  - 关闭延迟 200ms：鼠标斜着移到下拉框的路上不会提前关掉。
  - 键盘聚焦（`:focus-within`）和点击箭头（`.open`）不加延迟，立即打开。

**F5：文字和箭头之间的高亮会断开（对应 S3）**
- **现状：**链接的悬停背景只覆盖文字，箭头按钮是单独的元素，还用 `margin-left: -6px` 叠在一起。鼠标从文字移到箭头时，背景会消失一下再出现。
- **修改：**悬停时把文字和箭头当作一个整体高亮。可以用 `.nav-item.has-sub:hover > a` 加背景，并去掉负外边距造成的缝隙或重叠。

**S4、S5：**如果复现了而 F1–F5 没有解决，在汇报里描述现象并附录屏，不要自行改动其他结构，交给我判断。

## 4. 不改的部分
- 导航结构、文字、链接和配色都不变（header 背景色本来就是这个深绿，只是去掉透明度）。
- 首页 hero 的地球动画保留。
