## 4. Deviations from the task document

1. **Second button links to `/trade#enquiry`, not `/trade#register`.** The v1.1 brand site has no `#register` anchor; the form section is `#enquiry`. Button text is "Trade enquiry" instead of "Become a stockist" for the same reason, both labels are in the check-links whitelist.
2. **Target Market reads "Worldwide, starting with Australia and New Zealand".** The document said "Australia, then New Zealand", which predates the v1.1 positioning of evsider.com as a global B2B site with regional sites to follow. Model is "B2B Trade Supply", as the document says.
3. **Status stays "In Development".** The brand site is live, but the venture has no customers yet, and the site's own status definition reserves Operating for "live with customers or users". Say the word and it becomes Operating in one line.
4. **Reveal fallback added (`1a5476b`).** While verifying the page I found that every `.reveal` block on the group site stays at `opacity: 0` when the intersection observer never fires, which is the case for print, PDF, capture tools and any page where `main.js` is blocked. The site now marks everything visible after 2 seconds. Normal browsing is unaffected.
5. **Section padding trimmed on this page only (`a185ab6`)**, because the shortened page left a long empty band under the buttons.
